# Content publishing checklist

Complete this for each page or substantial content change. Record evidence or the responsible reviewer next to an item. An unchecked material item means the page needs work, a narrower scope, or deferral.

## Purpose and search fit

- [ ] The reader and task are clear.
- [ ] The content format matches the intended search task.
- [ ] The primary query was reviewed in the relevant market, or its uncertainty is recorded.
- [ ] An existing page cannot answer the same task more effectively through an update.
- [ ] The page adds a specific original tool, experience, interview, or verified detail.
- [ ] The opening gives the reader a useful answer or outcome promptly.

## Facts and responsibility

- [ ] The current foundation mission is used rather than superseded brand material.
- [ ] Geography, active services, eligibility, costs, dates, roles, and availability are confirmed where stated.
- [ ] Any unconfirmed detail is omitted or clearly described as a plan where appropriate.
- [ ] No other Agape entity's facts, reviews, registration, or history are imported.
- [ ] No invented founder biography, impact statistic, partner, testimonial, award, or funding claim appears.
- [ ] Real versus illustrative examples are clear.
- [ ] A responsible editor and relevant subject reviewer are identified truthfully.
- [ ] Permissions cover photographs, quotations, people, and named organizations.

## Reader usefulness

- [ ] The page completes its stated task without requiring a search elsewhere for a missing essential step.
- [ ] Sources are primary or authoritative for the claim and their current content was checked.
- [ ] Tools work in HTML and remain useful without a download or login.
- [ ] Language respects family choices, identity preferences, privacy, and practical limits.
- [ ] Safety-sensitive, legal, financial, healthcare, and benefits topics have appropriate qualified review or a narrower non-advisory scope.
- [ ] No service or role is promised merely because the keyword is attractive.

## Readability and metadata

- [ ] Headings explain the topic and form a coherent outline.
- [ ] Paragraphs develop one main point; long sentences and unnecessary jargon were reviewed.
- [ ] The title and description are unique, concrete, and accurate.
- [ ] Important wording comes early; the description adds information rather than repeating the title.
- [ ] Character counts were checked as display guides, not rigid ranking rules.
- [ ] The canonical path and any intentional indexability choice are correct.
- [ ] Image alternatives describe purpose without keyword stuffing.

## Journeys and technical release

- [ ] A resource hub and a relevant existing page link to the new page.
- [ ] All linked destinations exist and are appropriate to the reader's task.
- [ ] The primary next step works or honestly explains its current limits.
- [ ] Contact success is not claimed while delivery is unavailable.
- [ ] Gift completion is not claimed from a checkout click or placeholder page.
- [ ] Any structured data matches visible information and uses approved facts.
- [ ] Sitemap includes the published canonical URL and excludes drafts.
- [ ] Production export, page behavior, keyboard use, mobile layout, and relevant accessibility checks pass.
- [ ] No credentials, private applications, reviewer notes, or SEO planning files enter the published assets.

## Measurement and maintenance

- [ ] Events use approved definitions and contain no personal message or payment information.
- [ ] Test interactions are not counted as real outcomes.
- [ ] Publish date, substantive update date, next review date, and owner are recorded.
- [ ] Local/provider details have verification dates and a correction route.
- [ ] The release record includes commit, production URL, checks, and any deferred follow-up.

## Review record

| Item | Record |
| --- | --- |
| Page and canonical path | Enter the actual published path |
| Editor and review date | Enter actual responsible person and date |
| Subject review | Reviewer, scope, and date, or not applicable |
| Factual approval | Approved fact source and date |
| Publication decision | Ready, revise, narrow scope, or defer |
| Next review | Date and owner |
