# Social image fonts

The Open Graph generator uses local Montserrat 600 and Source Sans 3 600 TrueType files, matching the website typography. These assets are read at build time and require no font download during image generation.

Original files were downloaded from Google Fonts:

- [Montserrat 600](https://fonts.gstatic.com/s/montserrat/v31/JTUHjIg1_i6t8kCHKm4532VJOt5-QNFgpCu173w5aX8.ttf)
- [Source Sans 3 600](https://fonts.gstatic.com/s/sourcesans3/v20/nwpBtKy2OAdR1K-IwhWudF-R9QMylBJAV3Bo8Kxm7GEK9C4.ttf)

Each font's SIL Open Font License is included in this directory.
