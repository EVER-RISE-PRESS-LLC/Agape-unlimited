# Agape Unlimited website direction

The client's October 7 brief is the content authority. The existing brand guide informs visual decisions, but its earlier mission and proposed tagline are superseded by this brief.

## Tokens
- Foundation Navy #082A52: display type, navigation, purpose panel.
- Care Gold #D7A53B: action backgrounds and small supporting details.
- Warm Ivory #F7F4ED: open, welcoming page canvas.
- White #FFFFFF: seal placement, program information, cards.
- Soft Blue #E9F1FA: supporting program surfaces.
- Text Ink #233244: body copy.
- Montserrat 600/700 headings and Source Sans 3 400/600 body, as recommended in the supplied guide.

## Layout
Left-aligned oversized mission typography balances a tall founder photograph; the portrait has a broad arch, echoing the seal's circle and conveying welcome. Quiet navigation sits above this first composition. Three core commitments follow as open columns. Programs use an accessible expandable index, keeping the complete scope readable without ten repetitive cards. A navy purpose section pairs the supplied community photograph with the client's promise; values and involvement follow.

    [ seal + name          about / work / values       get involved ]
    [ large two-part headline             / founder portrait \    ]
    [ short mission + two clear paths     |                  |    ]
    [ children                  families              communities ]
    [ mission + vision         explorable program index           ]
    [ community photo          purpose / promise in navy           ]
    [ six values across an open grid                              ]
    [ ways to participate      contact availability                ]

## Review before implementation
A generic charity treatment would use unverifiable impact numbers, stock volunteer photos, a donation amount selector, and repeated animated cards. None serves the supplied evidence. Revised direction uses the client's real imagery, programs described as possible initiatives, and the actual mission as the main visual material. The brand's ivory is retained because it is explicit in the supplied guide. The distinctive moment is the oversized headline beside the arched portrait; other sections remain quiet.

## Motion vocabulary and Apple principles
Press / Tap feedback: a subtle scale-down when an element is clicked, so it feels physical. Origin-aware animation connects the mobile menu to its trigger. One short stagger on the initial hero establishes hierarchy; no repeating or per-section scroll effects. All controls remain interruptible. Keyboard input bypasses movement. Reduced motion retains brief opacity feedback, and reduced transparency uses solid surfaces.
